Private IP Address Ranges Explained (RFC 1918)

The Internet Engineering Task Force (IETF) reserved specific ranges of IPv4 addresses strictly for private local area networks (LAN). These addresses cannot be routed across the public internet:

Class IP Address Range Default Mask Typical Use
Class A 10.0.0.0 – 10.255.255.255 255.0.0.0 (/8) Enterprise networks & Xfinity Gateways (10.0.0.1 Guide →)
Class B 172.16.0.0 – 172.31.255.255 255.240.0.0 (/12) Medium corporate networks, Docker & VPN subnets
Class C 192.168.0.0 – 192.168.255.255 255.255.255.0 (/24) Home routers (192.168.1.1, 192.168.0.1, 192.168.2.1)
⚠️ Avoiding IP Conflicts on Two Routers

If connecting a secondary router, ensure both do not share the same IP (192.168.1.1). Change the secondary router to 192.168.2.1 or switch it to Access Point (AP) mode.

🛠️ Rescuing an Unresponsive Router

If DHCP fails, set a static IP like 192.168.1.50 with subnet 255.255.255.0 to reconnect.

Gateway IP FAQs

Why do different router brands use different IP addresses?

Manufacturers select default subnets defined by RFC 1918. For instance, TP-Link and D-Link commonly use 192.168.0.1, Netgear and Linksys use 192.168.1.1, and Comcast/Xfinity uses 10.0.0.1 to avoid default subnet collisions with customer equipment.

Can I change my router's default gateway IP address?

Yes, inside your router's LAN or Network settings you can change the Gateway IP (for example from 192.168.1.1 to 192.168.10.1). Note that all connected devices will renew their DHCP leases with the new IP range.

Why is my router IP not loading in the browser?

Verify you are directly connected to your router via Wi-Fi or Ethernet cable, ensure you are using 'http://' rather than 'https://', and check that no VPN or proxy is active on your device.
