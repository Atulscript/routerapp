    Step-by-step

    Log in to 192.168.1.1

    Four steps, with help at each one if something doesn't work.

    Step 1 of 4

    1. Join the Wi-Fi network of your TP-Link router, or plug a network cable into one of its LAN ports. You don't need internet access for this, only a connection to the router itself.

      On a phone, turn off mobile data while you set things up, and switch off any VPN.

      Can't find the network?

      The Wi-Fi name (SSID) and its password are printed on a sticker on the bottom or back of the router.

      If the router is new, plug it in and wait two minutes for its lights to settle before connecting.

    2. Open http://192.168.1.1 ↗

      Type it in the address bar, not in a search box. Search engines can't reach your router.

      The page won't load

      Router addresses are numbers only. 192.168.l.l and 192.168.o.1 use letters and end up in a search engine instead.

      Use http://, not https://, and try a private window if an old page is cached.

      Your router may use a different address. Find it:

      1. Press Windows + R, type cmd and press Enter.
      2. Type ipconfig and press Enter.
      3. Read the number next to "Default Gateway".
      1. Open System Settings › Network.
      2. Select your Wi-Fi, then click Details.
      3. Open the TCP/IP tab and read "Router".
      1. Open Settings › Wi-Fi.
      2. Tap the ⓘ next to your network.
      3. Read the number next to "Router".
      1. Open Settings › Network & internet › Internet.
      2. Tap the gear next to your Wi-Fi network.
      3. Open Advanced and read "Gateway".

    3. Username admin
      Password admin / password

      Newer routers ship with a unique password printed on a sticker underneath, so check there before trying the defaults.

      The password doesn't work

      Try the other common pairs: admin / admin, admin / password, admin with an empty password, or user / user.

      Routers from an internet provider often use a password printed on the label, not a standard one.

      As a last resort, hold the recessed Reset button with a paperclip for 10–15 seconds. That erases every setting, including your Wi-Fi name and password, so you'll set the router up from scratch.

    4. You're in. These four changes matter most:

      All four done. Your network is in much better shape.

      Generate a strong password Make a Wi-Fi QR code

      Can't find these settings?

      Menu names differ by brand. Admin password sits under System, Administration or Management. Wi-Fi security sits under Wireless or WLAN.

      Write the new passwords down somewhere safe before you save them.

    That's everything. If you get stuck later, reopen any step above.

    Frequently asked questions

    Why does 192.168.1.1 show "Site cannot be reached"?

    Ensure your device is connected to your router WiFi/Ethernet. Verify your default gateway using ipconfig in Command Prompt.

    What if "admin/admin" doesn't work?

    Check the physical sticker on the bottom of your router for custom factory credentials. If changed, hold the Reset button for 10 seconds to restore factory defaults.

    Is it 192.168.l.l or 192.168.1.1?

    IP addresses only contain numbers! 192.168.l.l uses lowercase letter "L" by mistake and will result in a search engine query instead of opening your router.
