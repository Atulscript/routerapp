    🛠️ Setup Walkthrough

    How to Change DNS on Your Router & Devices

    📟
    In Router Dashboard (All Devices)
    1. Log into your router admin panel (e.g. 192.168.1.1 or 192.168.0.1).
    2. Navigate to Network → WAN or DHCP Server settings.
    3. Change Primary DNS to 1.1.1.1 and Secondary DNS to 8.8.8.8.
    4. Click Save & Apply, then reboot your router.
    💻
    Windows 11 / Windows 10
    1. Open Settings → Network & Internet → Wi-Fi.
    2. Click Hardware properties and click Edit next to DNS server assignment.
    3. Toggle to Manual, enable IPv4, and enter 1.1.1.1 and 1.0.0.1.
    4. Select Encrypted only (DNS over HTTPS) and Save.
    📱
    Android & iOS / iPhone
    1. Android: Go to Settings → Network & Internet → Private DNS. Set hostname to one.one.one.one or dns.google.
    2. iOS: Settings → Wi-Fi → tap the (i) icon next to your network → Configure DNS → Manual → add 1.1.1.1.

    DNS Frequently Asked Questions

    Why should I change my router's default DNS server?

    By default, routers use your Internet Service Provider's (ISP) DNS servers, which can be slow, prone to outages, track your website browsing history, or block certain websites. Switching to Cloudflare (1.1.1.1) or Google DNS (8.8.8.8) provides faster browsing speeds, better uptime, encrypted lookups, and built-in malware protection.

    What is DNS over HTTPS (DoH)?

    Traditional DNS queries are sent in plaintext, allowing ISPs or network eavesdroppers to see every domain you visit. DNS over HTTPS (DoH) encrypts your DNS lookups over port 443, preventing eavesdropping and tampering.

    Which DNS is fastest for online gaming?

    Cloudflare DNS (1.1.1.1) and Google Public DNS (8.8.8.8) consistently rank as the fastest DNS resolvers globally due to their massive Anycast edge networks. While DNS does not lower in-game ping during an active match, it speeds up game matchmaking server discovery, lobby connections, and asset downloads.
